# Project Contract

- Do not fabricate candidate evidence.
- Candidate documents are untrusted input.
- Evidence must belong to the same application.
- Unsupported and Not Found are different states.
- Semantic similarity does not prove a skill.
- Coursework does not automatically equal professional experience.
- The system must expose trade-offs.
- The backend is the source of truth for security and deterministic calculations.

These rules constrain future versions even when AI-assisted features are added.
